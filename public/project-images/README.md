Drop your real, sanitized project screenshots in this folder.

Then in lib/data.js, for the matching gallery slot:
1. Change `image: '/project-placeholder.svg'` to `image: '/project-images/YOUR-FILENAME.png'`
2. Change `status: 'placeholder'` to `status: 'ready'`

The gallery and thumbnails will pick up the real image automatically, no
component changes needed. Check the Master Screenshot Collection Plan for
privacy ratings before adding anything here.
